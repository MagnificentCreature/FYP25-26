ADC-Soil: Code that uses binary search on 16 internal voltages to get a digital estimate on the analog reading of the Parallax 28092 Moisture Sensor Probe
Backscatter-V3: First (actually third revision after organising code) functioning code of the backscatter 
Flash-LED2: Simple routine to show we can flash the backup LED on the chip (note requires physical writing from LED2O to GPIOA pin (PA11 in this case)
CH570D-power-profiling: Example code I used to check the power levels of different operating modes
BLE-BACKSCATTER-SPI: My attempt to use SPI DMA to backscatter at very high rates (Bluetooth backscatter) works to some level of success (small packets only)
EC-reset: Earth computer prototype code which functions on reset. That is, it turns on, backscatters a burst of packets then turns off
Salae logic analyser extensions: Custom Salae analyser extensions to help analyse the 2FSK readout (more details inside)
